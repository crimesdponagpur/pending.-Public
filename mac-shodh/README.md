# शोध (Shodh): Mac वरील offline AI माहिती ॲप

तुमच्या Google Drive / Mac फोल्डरमधील Excel, Word, PDF फाइल्स वाचून, तुम्ही मराठीत जे मागाल ते तयार करून देणारे Mac ॲप. उदा. "NDPS गुन्हे 2024 vs 2025 ठाणेनिहाय तुलना chart". Chart, तक्ता आणि निरीक्षण Word / Excel / PDF मध्ये जतन करता येतात.

- **पूर्ण फुकट:** कोणतेही पैसे लागणारे API नाही.
- **offline:** AI (Ollama) Mac वरच चालते. एकदा सेटअप झाले की इंटरनेट लागत नाही.
- **गोपनीय:** माहिती Mac बाहेर जात नाही.
- **खरे Mac ॲप:** स्वतःची खिडकी, Dock मध्ये icon. ब्राउझर लागत नाही.

## हे कसे काम करते

1. ॲप फोल्डरमधील (उप-फोल्डरसह) सर्व फाइल्स वाचते. Excel ची प्रत्येक ओळ तिच्या स्तंभांसह (पोलीस ठाणे, गु.र.नं., दिनांक, कलम...) लक्षात ठेवते. एकाच स्तंभांच्या अनेक फाइल्स (उदा. दर महिन्याची) एकाच तक्त्यासारख्या धरल्या जातात.
2. तुम्ही मराठीत विनंती लिहिता.
3. **AI ठरवते काय मोजायचे:** कोणता तक्ता, कोणता फिल्टर (उदा. कलम मध्ये "NDPS"), कशानुसार गट (ठाणे), कशाची तुलना (वर्ष 2024 vs 2025).
4. **आकडे ॲप स्वतः मोजते**, तुमच्या खऱ्या ओळींवरून. AI आकडे लिहित नाही, त्यामुळे chart मधील आकडे चुकत नाहीत. स्क्रीनवर "AI ने असे मोजले" असे स्पष्ट लिहून येते, ते तपासता येते.
5. Chart + तक्ता + AI चे 3-5 मुद्दे निरीक्षण दिसते. **Word / Excel / PDF** बटण दाबून जतन करा. Excel मध्ये तुलना तक्ता, chart चे चित्र आणि "मूळ ओळी" (ज्या ओळी मोजल्या त्या) मिळतात.
6. पत्र, सारांश, टिपण मागितले तर AI फोल्डरमधील संबंधित परिच्छेद वाचून लिहिते आणि स्रोत [1], [2] देते.
7. AI बंद असेल तर साधा शोध: जुळणाऱ्या ओळी/परिच्छेद, फाइल व ओळ/पान क्रमांकासह.

## Mac वर सेटअप (एकदाच, सुमारे 20 मिनिटे, इंटरनेट लागेल)

### 1. Google Drive for desktop (फाइल्स Drive मध्ये ठेवायच्या असतील तर)

1. https://www.google.com/drive/download/ वरून "Drive for desktop" install करून आपल्या Google खात्याने login करा.
2. Drive मध्ये एक फोल्डर बनवा, उदा. `Mahiti`, आणि त्यात Excel/Word/PDF टाका.
3. Finder मध्ये त्या फोल्डरवर right-click → **Available offline** निवडा. म्हणजे फाइल्स Mac वर कायम राहतील आणि offline पण चालेल.

महत्त्वाचे: Drive मधील **Google Sheets / Google Docs** (हिरव्या/निळ्या icon च्या) फाइल्स Mac वर फक्त लिंक असतात, त्या वाचता येत नाहीत. त्या File → Download → Microsoft Excel (.xlsx) / Word (.docx) करून त्याच फोल्डरमध्ये ठेवा. ॲप अशा किती फाइल्स सोडल्या ते सांगते.

### 2. Node.js

https://nodejs.org वरून "LTS" आवृत्ती install करा.

### 3. Ollama (फुकट offline AI)

1. https://ollama.com वरून Mac साठी Ollama install करा.
2. Terminal उघडा (Spotlight मध्ये "Terminal") आणि मॉडेल घ्या:
   ```
   ollama pull qwen2.5:3b
   ```
   (सुमारे 2 GB. M1 8 GB RAM साठी योग्य.) मराठी लिखाण अधिक चांगले हवे असेल तर हेही घ्या: `ollama pull gemma3:4b`. ॲपमध्ये मॉडेल निवडता येते.
3. Ollama बसवलेले असेल तर शोध ॲप उघडताना ते आपोआप सुरू होते.

### 4. शोध ॲप

1. GitHub वरून: Code → Download ZIP, उघडून आतील `mac-shodh` फोल्डर `Documents` मध्ये ठेवा.
2. `make-app.command` वर right-click → Open → Open. हे `Shodh.app` बनवून Applications मध्ये टाकते (5-10 मिनिटे).
3. पुढे Launchpad / Dock मधून **Shodh** उघडा. पहिल्यांदा Mac विचारले तर right-click → Open.
4. ॲपमध्ये **Google Drive वापरा** बटण दिसेल, किंवा **फोल्डर निवडा** दाबून Drive मधील `Mahiti` फोल्डर निवडा.

(ॲप न बनवता थेट चालवायचे असेल तर `start.command` डबल-क्लिक करा.)

## वापर

- विनंती उदाहरणे:
  - `NDPS गुन्हे 2024 vs 2025 ठाणेनिहाय तुलना chart`
  - `2025 मधील महिनानिहाय चोरीचे गुन्हे line chart`
  - `प्रलंबित गुन्हे ठाणेनिहाय pie chart`
  - `रमेश पाटील याच्याबद्दल सर्व माहितीचा अहवाल`
- AI ने चुकीचा स्तंभ/फिल्टर घेतला तर विनंती अधिक स्पष्ट लिहा, उदा. "कलम स्तंभात NDPS", "दिनांक स्तंभानुसार वर्ष".
- Drive मध्ये नवीन फाइल आली तर ॲप दर 10 मिनिटांनी आपोआप वाचते; लगेच हवे असेल तर **पुन्हा वाचा**.
- M1 8 GB वर एका उत्तराला 10-30 सेकंद लागू शकतात.

## कोणत्या फाइल्स वाचल्या जातात

`.xlsx .xls .csv .docx .pdf .txt .md .json .html`

- जुन्या `.doc` फाइल्स: Word मध्ये उघडून `.docx` म्हणून Save करा.
- स्कॅन केलेले PDF (फोटो) वाचले जात नाहीत.
- कृतिदेव फॉन्टमधील मजकूर Unicode शोधात सापडत नाही.

## गोपनीयता

- ॲपचा सर्व्हर फक्त याच Mac च्या आत (`127.0.0.1`) चालतो.
- "वेबवरही शोधा" टिक केले तरच इंटरनेट वापरले जाते (DuckDuckGo), अन्यथा नाही.
- शोध-यादी `~/Library/Application Support/Shodh` मध्ये राहते.

## रचना (तांत्रिक)

| फाइल | काम |
|---|---|
| `main.js`, `preload.js` | Mac ॲप (Electron): खिडकी, PDF जतन, फोल्डर निवड |
| `server.js` | आतील स्थानिक सर्व्हर |
| `lib/extract.js` | PDF / Word / Excel मधून मजकूर व ओळी |
| `lib/indexer.js` | शोध-यादी (MiniSearch) |
| `lib/tables.js` | Excel ओळींवर फिल्टर / गट / तुलना मोजणी |
| `lib/ai.js` | Ollama: काय मोजायचे ते ठरवणे, निरीक्षण/अहवाल लिहिणे |
| `lib/output.js` | Word / Excel / PDF |
| `public/index.html` | ॲपचे पान (chart: Chart.js, offline) |

Terminal मधून: `npm install`, मग `npm start` (ॲप) किंवा `npm run web` (ब्राउझरमध्ये `localhost:3939`), `npm run dist` (Shodh.app / .dmg).
