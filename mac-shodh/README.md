# शोध: Mac वरील माहिती शोधणारे ॲप

तुमच्या Mac वरील एका फोल्डरमधील Excel, Word, PDF, txt फाइल्स शोधते आणि हवी ती माहिती Word / Excel / PDF मध्ये तयार करून देते. सर्व काही याच Mac वर चालते. पैसे लागत नाहीत आणि माहिती Mac बाहेर जात नाही.

## हे कसे काम करते

1. ॲप सुरू झाले की फोल्डरमधील (उप-फोल्डरसह) सर्व फाइल्स वाचते आणि शोधासाठी यादी (index) बनवते. पुढच्या वेळी फक्त नवीन/बदललेल्या फाइल्सच वाचते.
2. Excel ची प्रत्येक ओळ तिच्या स्तंभांच्या नावांसह (उदा. पोलीस ठाणे, गु.र.नं., आरोपी) लक्षात ठेवते. Word/PDF चे परिच्छेद पान क्रमांकासह.
3. तुम्ही मराठी किंवा इंग्रजीत लिहा, उदा. `सदर ठाण्यातील प्रलंबित चोरी`. जुळणाऱ्या ओळी, फाइलचे नाव व ओळ/पान क्रमांकासह दिसतात.
4. **Excel** बटण: त्याच मूळ स्तंभांचा तक्ता (.xlsx).
   **PDF** बटण: तोच तक्ता छपाईसाठी उघडतो, तिथे "Save as PDF" करा. (मोठा तक्ता असेल तर आपोआप आडवे पान.)
   **Word** बटण: तक्ता व परिच्छेद .docx मध्ये.
5. ऐच्छिक **AI**: Ollama बसवले तर "AI ने उत्तर लिहा" टिक करा. ते सापडलेल्या माहितीवरूनच सारांश/अहवाल/तक्ता लिहिते आणि स्रोत क्रमांक देते.
6. ऐच्छिक **वेब शोध**: "वेबवरही शोधा" टिक केले तर DuckDuckGo वरून निकाल जोडते (हेच एक काम इंटरनेट वापरते).

## Mac वर पहिल्यांदा सेटअप (एकदाच, 10 मिनिटे)

1. **Node.js बसवा:** https://nodejs.org वरून "LTS" आवृत्ती डाउनलोड करून install करा (फुकट).
2. **हा `mac-shodh` फोल्डर Mac वर ठेवा**, उदा. `Documents/mac-shodh`.
   (GitHub वर: Code → Download ZIP, उघडून आतील `mac-shodh` फोल्डर घ्या.)
3. **माहितीचा फोल्डर:** तुमच्या फाइल्स एका फोल्डरमध्ये ठेवा, उदा. `Documents/Mahiti`.
4. **सुरू करा:** `start.command` वर डबल-क्लिक करा.
   - पहिल्यांदा Mac "unidentified developer" म्हणेल: फाइलवर right-click → Open → Open.
   - पहिल्यांदा आवश्यक भाग डाउनलोड होतील (इंटरनेट लागेल, 1-2 मिनिटे).
5. ब्राउझरमध्ये `http://localhost:3939` आपोआप उघडेल. वरच्या चौकटीत तुमच्या फोल्डरचा पत्ता लिहा (उदा. `~/Documents/Mahiti`) आणि **फोल्डर बदला** दाबा.

पुढे रोज: फक्त `start.command` डबल-क्लिक. बंद करायचे असेल तर ती Terminal खिडकी बंद करा.

Terminal मधून चालवायचे असेल तर:

```
cd ~/Documents/mac-shodh
npm install
npm start -- ~/Documents/Mahiti
```

## फुकट AI (ऐच्छिक): Ollama

1. https://ollama.com वरून Mac साठी Ollama डाउनलोड करून install करा.
2. Terminal मध्ये एक मॉडेल घ्या (एकदाच, 2-5 GB डाउनलोड):
   - `ollama pull qwen2.5:7b` (मराठी बऱ्यापैकी, 16 GB RAM असल्यास उत्तम)
   - `ollama pull gemma2:2b` किंवा `qwen2.5:3b` (8 GB RAM असल्यास, कमी अचूक)
3. Ollama चालू असेल तर ॲपमध्ये "AI तयार" दिसेल.

AI फक्त सापडलेल्या माहितीवरूनच लिहिते, पण तरीही चूक करू शकते. महत्त्वाची माहिती स्रोत फाइलमध्ये तपासा (फाइलच्या नावावर क्लिक केले की ती फाइल उघडते).

## कोणत्या फाइल्स वाचल्या जातात

`.xlsx .xls .csv .docx .pdf .txt .md .json .html`

- जुन्या `.doc` फाइल्स वाचल्या जात नाहीत: Word मध्ये उघडून `.docx` म्हणून Save करा.
- स्कॅन केलेले PDF (फोटो) वाचले जात नाहीत, फक्त मजकूर असलेले PDF.
- कृतिदेव फॉन्टमधील मजकूर Unicode शोधात सापडत नाही.

## गोपनीयता

- सर्व्हर फक्त याच Mac वरून उघडतो (`127.0.0.1`), इतर कॉम्प्युटर/फोनवरून नाही.
- फाइल्सची यादी `mac-shodh/.cache` मध्ये राहते. ती हटवली तरी चालते, पुढच्या वेळी पुन्हा बनते.
